도면을 고정 격자(모눈)로 관리하며, **엑셀 셀을 칠하듯** 설비·장비·센서와 배선 경로, 설치/점검 상태를 마우스 드래그로 빠르게 배치하는 웹 기반 배치도 편집기입니다.

공장 설비 배치도뿐 아니라 **좌석 배치 · 창고 구획 · 매장 진열 · 전시 부스** 등 격자로 표현되는 모든 배치 작업에 쓸 수 있습니다. 그려 둔 도면은 휴대폰으로 읽고(`/m`), RFID 리더 상태를 얹어 벽걸이 현황판으로 띄울 수 있습니다(`/live`).

| | |
|---|---|
| **무엇인가** | 브라우저에서 도는 격자 배치도 편집기 + 모바일 보기 + 실시간 현황판 |
| **누가 쓰는가** | 설비 배치도·구획도를 CAD 없이 빠르게 그리고 공유해야 하는 실무자 |
| **왜 격자인가** | 자유 도형 대신 칸 단위로 고정하면 위치가 어긋나지 않고, 좌표(가로 N · 세로 M)로 소통할 수 있습니다 |
| **데이터는 어디에** | 서버 폴더(`.grid-projects/`)에 리비전으로 저장. 백업·공유는 JSON, 보고서는 PNG |
| **설치가 필요한가** | Node.js 하나. `npm install` → `npm run dev` 로 바로 뜹니다 |

CAD는 무겁고, 엑셀은 인쇄하면 어긋나고, 파워포인트는 좌표가 없습니다. 그리는 사람과 읽는 사람이 **"3열 12행 저울 옆"** 처럼 같은 좌표로 말하고, A3 두 장에 나눠 인쇄했을 때 **어디서 잘리는지** 그리는 중에 보이게 하는 것이 이 편집기의 목적입니다.

## 특징

자세한 동작과 규칙은 **[docs/features.md](./docs/features.md)** 에 있습니다. 여기서는 무엇이 되는지만 적습니다.

- **격자 드래그 편집** — 브러시 · 지우개 · 직선 · 사각형 · 채우기 · 선택 도구로 칸을 칠합니다. 눈금자가 `가로 37 · 세로 12` 좌표를 보이고, 휠로 확대(커서 아래 고정), 가운데 버튼으로 화면을 옮깁니다. [→ 자세히](./docs/features.md#1-고정-격자-드래그-편집)
- **사용자 팔레트** — 상태(채움 색) · 장비(칸 이름 + 테두리) · 배선(선) 항목을 직접 추가 · 수정 · 삭제합니다. 채움 무늬(빗금 · 점 …)와 선 모양(점선 · 파선)으로 흑백 인쇄에서도 구분되고, 장비 테두리의 선 모양 · 진하기는 칸마다 정합니다. [→ 자세히](./docs/features.md#2-사용자-관리형-팔레트)
- **레이어** — 배경 · 설비 · 배선 3개 기본 레이어에 더해 최대 12개까지 만들고, 표시 · 잠금 · 순서를 따로 다룹니다. 배선만 · 설비만 인쇄할 수 있습니다. [→ 자세히](./docs/features.md#3-레이어-관리)
- **칸 정보** — 우클릭으로 식별자 · 메모 편집, 현장 사진(720p · 8장) · 영상(480p · 3편) 첨부, 사진 대장 인쇄 · 일괄 저장, 확대 보기. [→ 자세히](./docs/features.md#4-칸별-식별자--메모)
- **범위 선택 · 클립보드** — 복사 · 잘라내기 · 붙여넣기가 상대 위치와 연결을 유지합니다. [→ 자세히](./docs/features.md#5-범위-선택과-클립보드)
- **다중 페이지** — 페이지마다 격자 크기 · 셀 · 메모 · 용지 설정이 독립, 팔레트만 공용. [→ 자세히](./docs/features.md#6-다중-페이지)
- **인쇄 용지 경계선 · 용지 규격 PNG** — A4 · A3 · A2 · Letter 와 한 칸의 mm 를 정하면 몇 장에 어디서 잘리는지 그리는 중에 보이고, PNG 는 그 규격 그대로 장마다 파일로 나옵니다(범례 띠 · 워터마크 포함). [→ 자세히](./docs/features.md#7-인쇄-용지-경계선) · [PNG](./docs/features.md#11-용지-규격에-맞춘-png)
- **이력 · 저장 · 내보내기** — Undo/Redo 60단계, 서버 저장(리비전) 한 곳, JSON 백업 · 불러오기, 실제로 쓴 항목만 담는 범례. [→ 자세히](./docs/features.md#8-이력--저장--내보내기)
- **장치 대장** — 리더기 · 저울 · PLC 의 S/N · IP · MAC · 포트를 칸과 분리해 한 곳에서 관리하고, 칸은 장치를 참조만 합니다. CSV · 마크다운으로 내보냅니다. [→ 자세히](./docs/features.md#9-장치-대장-device-registry)
- **로컬 폴더 공유와 버전 이력** — 같은 폴더를 여러 사람이 쓰고, 저장마다 리비전이 남으며, 남이 먼저 저장했으면 덮어쓰기 · 사본 · 서버 것 열기 중에서 고릅니다. 계정도 DB 도 없습니다. [→ docs/server.md](./docs/server.md)
- **모바일 도면 보기 (`/m`)** — 휴대폰으로 서버 도면을 읽기만 하는 화면. 손가락으로 옮기고 키우고, 칸을 누르면 그 칸의 내용 · 사진 · 메모를 시트로 읽습니다. 30초마다 최신 판을 따라옵니다. [→ docs/mobile.md](./docs/mobile.md)
- **실시간 현황판 (`/live`)** — [RfidReaderMonitor](https://github.com/SYacuCLoud/RfidReaderMonitor) 가 MQTT 로 내는 RFID 리더 상태를 도면 위에 얹는 벽걸이 화면. 태그가 놓인 칸을 녹색으로 채우고 실물 이름(회사 DB 기준정보 매핑)과 경과 시간을 적으며, 들어낸 태그는 잔상으로 남습니다. 칸을 누르면 식별 이력, CSV 내려받기, 감시 PC 시계 편차 경고, 다른 발행자용 메시지 형식 프로필. [→ docs/live.md](./docs/live.md)
- **MCP 서버** — AI 에이전트가 같은 폴더의 도면을 만들고 고칠 수 있는 Model Context Protocol 서버. [→ docs/mcp.md](./docs/mcp.md)

## 사용법

### 시작하기

Node.js **22.13 이상**이 필요합니다.

```bash
npm install     # 처음 1회
npm run dev     # 개발 서버 — http://localhost:3200
```

늘 떠 있는 서버(포트 3100)로 두려면 한 번 등록하고, 그 뒤로는 `npm run deploy` 로 새 빌드를 올립니다.

```bash
scripts\service.cmd install    # 처음 1회: 로그온 시 자동 시작 등록 + 지금 시작
npm run deploy                 # 빌드 → 스냅샷 → 재시작
```

| 주소 | 화면 |
|---|---|
| `http://<서버 주소>:3100/` | 편집기 |
| `http://<서버 주소>:3100/m` | 모바일 도면 보기(읽기 전용) |
| `http://<서버 주소>:3100/live?id=<도면 id>` | 실시간 현황판(벽걸이) |

빌드 · 상시 서비스 명령 · 로그 · 기술 스택은 **[docs/setup.md](./docs/setup.md)**.

### 기본 조작

1. 첫 화면은 서버의 가장 최근 도면을 엽니다. 새 도면은 상단 `서버 도면` 줄에서 만듭니다.
2. 왼쪽 팔레트에서 항목을 고르고 도면 위를 끌어 칠합니다. 도구(브러시 · 지우개 · 직선 · 사각형 · 채우기 · 선택)는 툴바에서 바꿉니다.
3. 칸에서 **우클릭**하면 식별자 · 메모 · 사진 · 장치 연결을 편집합니다. 어떤 도구를 쓰고 있든 됩니다.
4. `인쇄 용지` 를 켜 용지와 한 칸의 mm 를 정하면 인쇄 경계가 도면 위에 보입니다. `PNG 저장` 이 그 규격으로 나옵니다.
5. `서버 저장` 이 유일한 저장입니다. 브라우저에는 저장하지 않으므로 서버가 없는 자리에서는 `JSON 내보내기` 로 남겨 두십시오.

### 키보드 단축키

| 키 | 동작 | 비고 |
|---|---|---|
| `Ctrl + Z` | 되돌리기 | 최대 60단계 |
| `Ctrl + Y` / `Ctrl + Shift + Z` | 다시 실행 | |
| `Ctrl + C` | 선택 범위 복사 | `선택` 도구 사용 시 |
| `Ctrl + X` | 선택 범위 잘라내기 | |
| `Ctrl + V` | 붙여넣기 | 클릭한 칸이 원점 |
| `우클릭` | 칸 정보(식별자 · 메모) 편집 | 도구 무관, 칸은 칠해지지 않음 |
| `Enter` | 칸 정보 저장 / 페이지 이름 확정 | |
| `Shift + Enter` | 메모 줄바꿈 | |
| `Esc` | 편집 상자 닫기 / 취소 | |
| `휠` | 확대 · 축소 | 커서 아래 지점 고정 |
| `가운데 버튼 드래그` | 화면 이동 | |

> macOS에서는 `Ctrl` 대신 `⌘`도 동작합니다. 텍스트 입력창에 커서가 있는 동안에는 `Ctrl+C/X/V`를 가로채지 않습니다.

### 실시간 현황판 붙이기

1. MQTT 브로커(예: Mosquitto, WebSocket 9001)를 띄우고 RfidReaderMonitor 의 MQTT 발행을 켭니다.
2. 편집기 **장치 대장**에 리더를 S/N 으로 등록하고 칸에 연결합니다. S/N 이 같으면 그 칸에 상태가 얹힙니다.
3. `/live?id=<도면 id>` 를 벽걸이 PC 즐겨찾기에 둡니다(편집기 도구 막대의 `실시간 현황판 ↗`). 브로커가 다른 PC 면 `&broker=ws://…:9001`.
4. UID 대신 실물 이름을 보이려면 오른쪽 **기준정보** 칸의 `설정` 에서 회사 DB 표의 열을 짝지어 줍니다. 접속(DB · 계정)은 관리자가 `.grid-projects/.lookup/connections.json` 에 한 번 적습니다.

토픽 · 페이로드 형식, 잔상 · 경과 시간 · 식별 이력 · 시계 편차의 규칙은 **[docs/live.md](./docs/live.md)**.
